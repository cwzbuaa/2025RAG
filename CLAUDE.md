## Project Overview

DeepCook is an AI-powered recipe assistant project based on LLaMA-Factory for fine-tuning large language models (Qwen2.5-7B default). It provides recipe recommendations, detailed recipe generation, and cooking Q&A through a Gradio web interface.

## Common Commands

```bash
# Install dependencies
pip install -r requirements.txt

# ========== SFT Scripts ==========
# Generate SFT training data from raw recipe data
python scripts/sft/generate_sft_data.py

# Merge SFT data files
python scripts/sft/merge_sft_data.py

# Run SFT training (uses Qwen2.5-7B by default)
python scripts/sft/run_sft.py

# Run SFT with custom model path
python scripts/sft/run_sft.py --cpt_model_path /path/to/model --output_dir output/sft

# Evaluate model
python scripts/sft/evaluate_model.py

# Deploy Gradio web interface
python scripts/sft/deploy_app.py

# ========== Retriever Scripts ==========
# Train RAG Retriever (BERT-based bi-encoder with contrastive learning)
python scripts/retriever/train_retriever.py

# Build FAISS index from trained retriever
python scripts/retriever/build_faiss_index.py

# Retrieve recipes using FAISS index
python scripts/retriever/retrieve.py --query "我有土豆和番茄，能做什么菜？"
python scripts/retriever/retrieve.py --interactive  # Interactive mode
```

## Architecture

### Directory Structure
- `data/` - Raw recipe data and processed SFT training data
- `data/source_data/` - Original recipe JSONL files (categorized: 菜谱-主食, 菜谱-水产, etc.)
- `data/sft_data/` - Generated SFT training data
- `scripts/` - Python scripts for data processing, training, evaluation, and deployment
  - `scripts/sft/` - SFT training scripts
  - `scripts/retriever/` - RAG retriever scripts
- `output/` - Model training output
  - `output/sft_lora/` - SFT LoRA fine-tuned model
- `index/` - FAISS vector index for retriever
  - `index/retriever/` - FAISS index files
- `docs/` - Deployment documentation

### Key Scripts (SFT)
| Script | Purpose |
|--------|---------|
| `scripts/sft/generate_sft_data.py` | Generates SFT training data from raw recipe JSONL files |
| `scripts/sft/merge_sft_data.py` | Merges multiple SFT data files into one |
| `scripts/sft/run_sft.py` | Runs LLoRA fine-tuning using LLaMA-Factory |
| `scripts/sft/evaluate_model.py` | Evaluates fine-tuned model performance |
| `scripts/sft/deploy_app.py` | Deploys Gradio web UI for the AI chef |

### Key Scripts (Retriever)
| Script | Purpose |
|--------|---------|
| `scripts/retriever/train_retriever.py` | Trains BERT-based bi-encoder with contrastive learning |
| `scripts/retriever/build_faiss_index.py` | Builds FAISS vector index from trained retriever |
| `scripts/retriever/retrieve.py` | Retrieves relevant recipes using FAISS index |

### Data Flow
1. Raw recipe data in `data/source_data/` (JSONL format)
2. Generate SFT data → `data/sft_data/`
3. Merge → `data/sft_data_merged.jsonl` + `data/dataset_info.json`
4. Fine-tune with LLaMA-Factory → `output/sft_lora/`
5. Build retriever index → `index/retriever/`
6. Deploy web interface → Gradio app

### Tech Stack
- PyTorch + Transformers
- LLaMA-Factory (fine-tuning framework)
- BERT (bert-base-chinese for retriever)
- FAISS (vector similarity search)
- Gradio (web UI)
- Qwen2.5-7B (default base model)

## Important Notes

- Default base model path: `E:/models/qwen2_5_7b` (configurable via `--cpt_model_path`)
- Training uses LoRA fine-tuning (`finetuning_type: lora`)
- Training config is auto-generated by `run_sft.py` to `output/sft_lora/sft_config.yaml`
- The web interface loads SFT model from `output/sft_lora/` after training completes
- Retriever uses bert-base-chinese, fine-tuned with contrastive learning
- Retriever model is saved to `output/retriever/retriever_model.pt`
- FAISS index is saved to `index/retriever/`
